## 🚀 Módulos y Funcionalidades Principales

### 1. 🏢 Sede Posadas — Arena LAN HQ
- **Gestión de Puestos & Bootcamps:** Cabinas insonorizadas 5v5 con monitores ZOWIE XL2566K 360Hz y placas RTX 4080 Super.
- **Telemetría de Red Local:** Switch 10Gbps SFP+, enlace simétrico de 1 Gbps y latencia local de <0.4ms.
- **Sistema de Reserva & Kiosco Pro:** Reserva de turnos y stock de consumibles de alto rendimiento (Zingaro Hydro Electrolitos, Energy Boost).

### 2. 🎓 Academia Zingaro (Metodología 5 Pilares)
- **Pilares:**
  1. *Mecánicas & Aim:* Crosshair placement, TTK, control de spray y recoil reset.
  2. *Táctica de Ronda & IGL:* Lectura de mapas, protocolos anti-eco y economía CS2 (MR12).
  3. *Preparación Física & Ergonomía:* Salud muscular de muñeca/antebrazo, postura cervical y estiramientos.
  4. *Mindfulness & Biofeedback:* Manejo de ritmo cardíaco en situaciones de clutch 1vX y reducción de tilt.
  5. *Análisis Forense GOTV:* Revisión de demos tick por tick con timestamps de error/acierto.
- **Staff:** Adniel (Head Coach), Pacuno_CS (IGL & Mentor), Lic. Gómez (Psicología Deportiva) y Lic. Duarte (Kinesiología).
- **Boletín de Rendimiento del Alumno:** Ficha integral con radar 5D, métricas individuales e historial de evolución.

### 3. ⚖️ Sistema Competitivo, Arbitraje & Servidores
- **Matchroom & Veto Dinámico:** Sala de partida en tiempo real con sistema de descarte de mapas y selección de servidores.
- **Pacto Bilateral de Horarios:** Coordinación formal entre capitanes con firma digital SHA-256.
- **Centro de Despachos & Notificaciones:** Avisos sincronizados a 128 ticks con integración para webhooks de Discord.
- **Jurisprudencia Arbitral & Log Forense:** Registro inmutable de disputas y auditoría de comisarios.
- **Servidores 128 Tick CS2:** Telemetría de servidores dedicados en Buenos Aires, San Pablo y Posadas LAN.

## 💻 Instalación y Ejecución Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/TU_USUARIO/zingaro-esports-os.git
   cd zingaro-esports-os
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar en modo desarrollo:**
   ```bash
   npm run dev
   ```
   Abrir `http://localhost:3000` en tu navegador.

4. **Compilar para producción:**
   ```bash
   npm run build
   ```
